# Don't Touch The Color!!!


https://youtu.be/UN7J72ygNmA


A Very fun Mod where you have to stay Alive by Not Touching specific Colors .

Forget Playing Minecraft the Normal WAY , Now You Must Pay Attention to The Color Changing every 10-15s , OR YOU WILL DIE!!!!.

it's Built for players to play with friends for some choas and fun yk.

# Start Item and start command " /start "

It's Pretty Much a start Item , that when right Click when Looking at a BLOCK , it will start the minigame and announce a color you must not touch.
That Color Changes every 10-15s Seconds.

![d](https://cdn.modrinth.com/data/cached_images/47c83b1d9435fd442461ccc05d9b53cbeb17782e.png)

# Stop Item and Stop Command " /stop "

it stops everything and makes stuff back to normal

![d](https://cdn.modrinth.com/data/cached_images/91976713525100e4716fdfe03dea8165448f97c6.png)


# Extra Items

I added a few Items that start the Minigame for Only 1 Color for inf amount of time,
